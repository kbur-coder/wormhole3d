# Wormhole 3D (кратко по-русски)

Трассировщик лучей в реальном времени для червоточины Эллиса: летишь сквозь горловину и видишь вторую вселенную. Каждый пиксель считает путь света по геодезическим линиям метрики червоточины. Полное описание на английском в [README.md](README.md).

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее (рекомендуется 20) и браузер с WebGL2.

    git clone https://github.com/kbur-coder/wormhole3d.git
    cd wormhole3d
    npm install
    npm run dev

Откроется адрес вида http://localhost:5173. Адрес `Network` из терминала открывает ту же страницу на телефоне в той же Wi-Fi сети.

## Запуск без сервера

    npm run build

Появится `dist/index.html`: один файл, в котором уже лежат код, шейдеры и three.js. Его можно открыть двойным кликом или залить на любой хостинг.

## Управление

Клик по странице захватывает мышь, мышь вращает камеру, W A S D летят, Space и C вверх и вниз, Q и E крен, Shift ускорение, Esc отпускает мышь. На телефоне: водить пальцем и держать палец, чтобы лететь вперёд.

## Настройка

Параметры добавляются в адрес страницы:

    http://localhost:5173/?throat=3&fov=1.6&initialScale=0.5

Главные параметры: `throat` радиус горловины, `startL` стартовая позиция (отрицательная начинает во второй вселенной), `fov` угол обзора в радианах, `initialScale` стартовое разрешение, `speed` и `boost` скорость, `maxSteps` число шагов трассировки (меньше значит быстрее). Полный список, диапазоны и рецепты для слабых компьютеров в [docs/configuration.md](docs/configuration.md). Все те же значения лежат в `src/config.js`.

## Деплой на Netlify

В репозитории есть `netlify.toml`, поэтому настройки вводить не нужно.

1. Залей репозиторий на GitHub.
2. В Netlify: Add new site, Import an existing project, GitHub, выбери репозиторий.
3. Ничего не меняй и нажми Deploy. Netlify сам запустит `npm run build` и опубликует папку `dist`. Каждый следующий push в `main` обновит сайт.

Без GitHub: выполни `npm run build` и перетащи папку `dist` на https://app.netlify.com/drop.

## Если не работает

Если страница чёрная, сверху красным будет написана причина (нет WebGL2, ошибка шейдера или не загрузился модуль), этот же текст виден в консоли браузера по F12. Если медленно, открой страницу с `?initialScale=0.4&maxSteps=120` и включи аппаратное ускорение в браузере. Нажми на страницу один раз, иначе мышь не захватится.
